# Pujanam – Pandit Booking & Puja Services Platform

## 📌 Overview

Pujanam is a full-stack web application designed to simplify the process of discovering puja services and booking verified pandits online. The platform provides a centralized system where users can explore available puja services, book pandits, and manage their bookings.

It provides dedicated dashboards for Users, Pandits, and Admins, enabling efficient booking operations, service management, and profile management through a role-based system.

## ✨ Key Features

- **User Authentication:** Secure JWT-based authentication and role-based authorization.
- **Role-Based Access:** Dedicated access and dashboards for Users, Pandits, and Admins.
- **Puja Services:** Browse and explore available puja services.
- **Pandit Booking:** Book verified pandits for different puja services.
- **Booking Management:** Manage and track booking information.
- **Service Management:** Manage puja service details and information.
- **Profile Management:** User and Pandit profile management.
- **Image Management:** Cloudinary integration for image uploads and storage.
- **Responsive UI:** Mobile-friendly and responsive interface built with React.js and Tailwind CSS.

## 🛠️ Technology Stack

| Category | Technologies |
|---|---|
| Frontend | React.js, Tailwind CSS |

| Database | MongoDB |
| Authentication | JSON Web Tokens (JWT) |
| Image Management | Cloudinary |
| API Architecture | REST APIs |

## 👥 User Roles

### 1. User
- Browse available puja services.
- Explore and book verified pandits.
- Manage personal profiles.
- Manage and track bookings.

### 2. Pandit
- Manage pandit profile information.
- Access booking-related information.
- Manage assigned bookings.

### 3. Admin
- Access administrative dashboard.
- Manage users and pandits.
- Manage puja services and bookings.

## 🏗️ Application Architecture

The application follows a client-server architecture:

- **Frontend:** React.js provides the user interface and role-specific dashboards.
- **Backend:** Node.js and Express.js handle business logic and REST API requests.
- **Database:** MongoDB stores user, pandit, puja service, and booking information.
- **Authentication:** JWT handles authentication and role-based authorization.
- **Media Storage:** Cloudinary manages uploaded images.

## 🔐 Security

- JWT-based authentication.
- Role-based authorization for different user types.
- Protected backend routes.
- Environment-based configuration for sensitive credentials.
